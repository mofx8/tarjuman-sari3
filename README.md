# ترجمان سريع — Quick Translate (Windows)

تطبيق ويندوز لترجمة النصوص إلى العربية (أو أي لغة) بسرعة: من الشاشة (OCR) أو من النص المحدد أو الحافظة.
Windows app that translates on-screen text, selections and clipboard into Arabic (or any language).

## الميزات
- ترجمة منطقة من الشاشة أو النص تحت المؤشر (يعمل على الشاشة التي عليها المؤشر، متعدد الشاشات/DPI).
- ترجمة النص المحدد في أي برنامج، وترجمة الحافظة.
- **كل الاختصارات قابلة للتعديل** (الإعدادات ← الاختصارات).
- عدة محركات مجانية مع احتياط تلقائي وكاش دائم + مفاتيح اختيارية (DeepL / Azure) لحد أعلى.
- تشغيل بصلاحية المدير بلا طلب UAC في كل مرة (مهمة مجدولة تُنشأ عند التثبيت).
- سجل ومفضلة، سمات فاتحة/داكنة، تخصيص الخط والألوان، تشغيل مع ويندوز، أيقونة بجانب الساعة.

## الاختصارات الافتراضية
| الإجراء | الاختصار |
|---|---|
| ترجمة منطقة (سحب) | Ctrl+Alt+T |
| ترجمة النص تحت المؤشر | Ctrl+Alt+Q |
| إعادة آخر منطقة | Ctrl+Alt+R |
| ترجمة النص المحدد | Ctrl+Alt+C |
| ترجمة الحافظة | Ctrl+Alt+V |
| إظهار/إخفاء النافذة | Ctrl+Alt+W |
| ترجمة مباشرة لمنطقة (تُحفظ لكل برنامج) | Ctrl+Alt+L |
| ترجمة مباشرة بمنطقة جديدة | Ctrl+Alt+Shift+L |
| ترجمة صورة من الحافظة | Ctrl+Alt+I |

داخل الشاشة المجمّدة: انقر نصاً لترجمته، اسحب لتحديد منطقة، Space إخفاء/إظهار، R إعادة، N جديد، Esc أو زر الفأرة الأيمن للإغلاق.

## ملاحظات
- OCR يستخدم محرك ويندوز المدمج؛ لقراءة لغة ما ثبّت حزمتها من إعدادات ويندوز (الوقت واللغة).
- المحركات المجانية غير رسمية وقد تتغير أو تُقيَّد؛ لذلك يوجد احتياط تلقائي، ويُنصح بإضافة مفتاح DeepL/Azure المجاني للثبات.
- الألعاب بوضع ملء الشاشة الحصري قد تمنع اللقط؛ استخدم Borderless.
